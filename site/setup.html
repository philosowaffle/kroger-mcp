Set up kroger-mcp

You need Docker, a Kroger shopping account and about ten minutes. These steps run the server on your own machine for Claude Code. To use it from claude.ai, the desktop app or your phone, see Hosting it for other devices.

  1. Create a Kroger developer app

    Sign up at developer.kroger.com. This developer account is separate from your shopping account.

    Open My Apps → Create App and give the app the Product, Cart, Profile and Locations APIs. Add this redirect URI:

    http://localhost:8080/kroger/callback

    Then copy the app's Client ID and Client Secret.

  2. Configure

    Download docker-compose.yml into a new folder and create a .env file next to it:

    KROGER_CLIENT_ID=your-client-id
KROGER_CLIENT_SECRET=your-client-secret

  3. Run it

    docker compose up -d

    This pulls ghcr.io/philosowaffle/kroger-mcp:latest (amd64 and arm64) and keeps the linked account's tokens in a Docker volume. The sample file only listens on 127.0.0.1.

  4. Connect Claude

    claude mcp add --transport http kroger http://localhost:8080

  5. Link your Kroger account

    Ask Claude to “link my Kroger account”. Open the URL it gives you, sign in with your shopping account and approve. Kroger sends you back to the server, which stores and refreshes the tokens. A link lasts about six months.

    Then ask Claude to find your store and make it your default, and you're ready to shop.

Hosting it for other devices

claude.ai, the desktop app and the mobile apps connect from Anthropic's servers, so they need a public HTTPS URL for the server. Before you expose it:

  • Turn on MCP auth with your own identity provider (for example Authelia), so only you can use the server. See Security.
  • Register https://your-host/kroger/callback as a redirect URI on the Kroger app and set KROGER_REDIRECT_URI to match it exactly.
  • Add a custom connector in Claude pointing at your server's URL.

The full configuration reference is in the README, and identity provider setup is in docs/authentication.md.
