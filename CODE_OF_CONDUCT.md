# Code of Conduct

kroger-mcp is hosted on GitHub, and everyone taking part (in issues, pull requests,
discussions, reviews and commits) is expected to follow the
[GitHub Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines)
and GitHub's
[Acceptable Use Policies](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies).

In short: be respectful, assume good intent, keep feedback about the work, and don't
harass, threaten, or post anyone's private information.

## Reporting

Report violations to GitHub. Use **Report content** from the `...` menu on the
comment, issue or pull request, or **Block or report** on the user's profile. See
[Reporting abuse or spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
GitHub reviews reports privately.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests and other
contributions that break these guidelines. They may also lock conversations or
block users from the repository.

Security vulnerabilities aren't conduct issues. Report them privately as described
in [SECURITY.md](SECURITY.md).
